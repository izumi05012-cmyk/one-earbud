# 踩过的坑

> 每一条都是真摔过的。格式：现象 → 原因 → 怎么处理（代码里在哪）。

## iPhone / PWA

1. **点了播放不响**
   苹果只认「手指点下去那一刻」同步发起的 `audio.play()`。如果点了以后才去服务器拿播放地址，拿回来再 play，已经不算用户操作，会被拦。
   → 播放地址要提前备好；点的那一下直接 play。`player.js`：`warmRestored()`、`toggle()`。

2. **彻底退出 PWA 再进来，听歌栏没了**
   → 把「正在放哪首、是列表里哪一项」存 localStorage（`one-earbud.last`），进来时恢复，并**悄悄预先拿好地址**（不放），第一下点播放才会响。宿主必须一打开页面就挂听歌栏。

3. **播放器停着时，TA 的 play_now 不会自己响**
   苹果不许网页没人碰就出声。→ 听歌栏先摆好这首，等 YOU 点一下。文档和工具返回里都要告诉 TA 这一点，免得 TA 以为「放了」。

4. **地址放久了过期**
   网易云的播放地址大约 20 分钟失效。暂停很久再点播放，会没声音。
   → `toggle()` 发现地址超过 15 分钟：先在手势里同步 play（占住苹果的许可），再换新地址接着放。

## 网络

5. **切 Wi-Fi / 流量时，歌没放完就跳下一首**
   断网那一下，苹果会把正在放的歌报成「ended」。
   → ended 时如果离结尾还有 5 秒以上，当作卡住：重拿地址从原位置接着放（每首只救一次）。

6. **一直「加载中」**
   网不好时 `audio.play()` 返回的 promise 可能一直不回。如果把「加载中」挂在它上面，就永远转圈。
   → 「加载中」只包拿地址那一段（10–12 秒超时）；play 不 await。另有看门狗：显示在放、进度 8 秒不动，就自动重拿地址（最多两次）。

7. **某些歌在流量下永远加载不出来**
   网易云把一部分歌放在 `m801.music.126.net`，它优先走 IPv6；有的运营商流量下 IPv6 连不上。同一个签名路径换到 `m701.music.126.net` 能正常下载。
   → `netease.js` 的 `playUrl()` 把 m801 改写成 m701。

8. **断网后报错一直挂着 / 歌词是空的**
   → 真正响起来（`play` 事件）时清掉报错；拿详情失败不拦播放，响了以后补拿歌词；`online` 事件时自动重试。

## 播放列表

9. **快放完时加的歌被跳过**
   为了两首之间不空档，剩 25 秒时会预取下一首；之后 YOU 或 TA 又加了歌，放完还是放了预取的那首。
   → 列表一变（加、删、挪、换模式），预取对不上就作废，重新预取。`player.js`：`takeQueue()`、`next()`。

10. **拖进度条到快结尾，下一首卡住**
    预取刚发出去这首就放完了，又并发拿一遍，两份挤在一起。→ 等在路上的那份（≤6 秒）。

11. **拖拽排序时手里那行突然被换掉**
    拖的过程中列表刷新（轮询、播放状态变化）会重画 DOM。→ 拖动中暂停重画，松手后再补。

12. **没版权的歌点了播放，响的是上一首**
    拿不到新地址时，audio 上还挂着上一首的地址。→ 失败就清掉 src；在列表里就 1.2 秒后自动跳下一首（连跳最多 5 首）。

## 前端工程

13. **改了代码手机上没变化**
    PWA 会强缓存 JS/CSS。→ 每次改前端，所有 import 和 `<script>`/`<link>` 的 `?v=` 一起换。

14. **报错显示成 `MUSIC_UNAVAILABLE` 这种代码**
    后端错误是 `{ ok:false, error:代码, message:给人看的话 }`，前端要用 message 给人看、code 给程序判断（`web/lib/api.js` 已经这么做）。

## TA 这边

15. **TA 在聊天里整段念歌词被拦下**
    很多模型对整段复述歌词有版权过滤，会直接拒答，YOU 那边看起来像 TA 卡住了。
    → 让 TA 引一两句、或者用 `share` 附行号发歌词卡，不要整段复述。

16. **「正在听」块在 YOU 早就关了 App 之后还出现**
    → 心跳 60 秒没来就当不在听；暂停超过 10 分钟也不带；点 × 当场清掉（`now-playing.js`）。

## 网易云账号

17. **登录态过期**
    → 接口返回 `MUSIC_LOGIN_EXPIRED`，前端 `onNeedLogin` 钩子里引导 YOU 去授权页重扫。
18. **服务器在海外，网易云拒绝**
    → `.env` 里填 `NETEASE_REAL_IP`（一个国内 IP）作为 X-Real-IP。
